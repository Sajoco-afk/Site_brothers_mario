# 🍄 Site Brothers Mario

Um site inspirado no universo de **Super Mario Bros.**, desenvolvido como projeto para praticar e demonstrar conhecimentos em **HTML, CSS e JavaScript**.

## 🎮 Sobre o projeto

O **Site Brothers Mario** é uma página web temática baseada no universo do Mario, utilizando recursos de desenvolvimento front-end para criar uma experiência visual interativa.

O projeto foi desenvolvido com foco em:

* Estruturação de páginas com HTML5
* Estilização e criação do layout com CSS3
* Interações e funcionalidades utilizando JavaScript
* Organização de arquivos e recursos de um projeto web

## 🚀 Como executar

### 1. Clone o repositório

```bash
git clone https://github.com/Sajoco-afk/Site_brothers_mario.git
```

### 2. Entre na pasta

```bash
cd Site_brothers_mario
```

### 3. Abra o projeto

Abra o arquivo:

```text
index.html
```

Você também pode utilizar uma extensão como **Live Server** no Visual Studio Code para executar o projeto localmente.

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de colocar em prática conceitos fundamentais de desenvolvimento web, principalmente:

* JavaScript
* Manipulação de elementos da página

* Desenvolvimento de interfaces temáticas

Durante o desenvolvimento deste projeto, foram praticados conceitos importantes de desenvolvimento web, como a criação de estruturas HTML, estilização com CSS e utilização de JavaScript para adicionar interatividade à página.
